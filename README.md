# FADDOUL HOLDINGS website

Bilingual (Arabic RTL / English) one-page site for a construction & concrete contractor in Lebanon.

## Structure
- `index.html` – markup
- `css/style.css` – styles (light/dark theme, RTL-aware)
- `js/main.js` – AR/EN translations, language toggle, WhatsApp quote form
- `images/` – project photos

## Run / deploy
Static site, no build step. Open `index.html`, or enable **GitHub Pages** (Settings → Pages → Deploy from branch → `main` / root).
